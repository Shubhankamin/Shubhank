# Shubhank's Personal Portfolio

Welcome to my personal portfolio website! This project is a modern, responsive, and visually engaging web application built to showcase my projects, skills, experience, and education. It features a space-themed dark mode aesthetic with elegant glassmorphism UI elements.

## ✨ Features

- **Modern Tech Stack:** Built with Nuxt 3 and Vue 3 for a blazing fast, server-side rendered experience.
- **Stunning UI/UX:** Features a space-themed dark background with a modern glassmorphism (glass finish) aesthetic.
- **Smooth Animations:** Integrated with GSAP and AOS (Animate On Scroll) for dynamic, smooth, and interactive micro-animations.
- **SEO Optimized:** Structured with semantic HTML and Nuxt's built-in SEO utilities to ensure high visibility.
- **Responsive Design:** Fully responsive layout utilizing Vuetify 3, ensuring it looks great on desktops, tablets, and mobile devices.
- **Interactive Components:** Includes sections for Experience, Education, Projects, Skills, and a Connect/Contact form.

## 🛠️ Technologies Used

- **Framework:** [Nuxt 3](https://nuxt.com/) / [Vue 3](https://vuejs.org/)
- **UI Component Library:** [Vuetify 3](https://vuetifyjs.com/)
- **Animations:** [GSAP](https://gsap.com/) & [AOS](https://michalsnik.github.io/aos/)
- **Styling:** Vanilla CSS & SCSS (Glassmorphism & Space Theme)
- **Backend/API:** Express & Nodemailer (for contact form functionality)

## 🚀 Setup & Installation

Make sure to install the dependencies before running the project:

```bash
# npm
npm install

# pnpm
pnpm install

# yarn
yarn install
```

## 💻 Development Server

Start the development server on `http://localhost:3000`:

```bash
# npm
npm run dev

# pnpm
pnpm run dev

# yarn
yarn dev
```

## 🏗️ Production Build

Build the application for production:

```bash
# npm
npm run build

# pnpm
pnpm run build

# yarn
yarn build
```

Locally preview the production build:

```bash
# npm
npm run preview
```

## 📂 Project Structure

- `components/` - Reusable Vue components (Hero, About, Projects, Experience, Connect, etc.)
- `pages/` - Application routes/views
- `assets/` - Static assets like images and global stylesheets
- `server/` - Backend API routes (e.g., mail sending)
